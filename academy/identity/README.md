# 两个独立课程品牌：第一版形象与命名

日期：2026-10-24。本轮按“先创建两个形象和名字”交付候选，不提前批量替换网站教练及其十八种表情。网站现有名称、头像和学习记录保持原状，课程推荐面板先完成独立发布。

## 问问哲学班

角色名：问问。原创小水豚，温暖的燕麦棕皮毛、苔绿色小马甲，拿着一本打开的深蓝笔记。眼神向上看，带一点认真追问的疑惑。它陪学习者澄清问题、找理由、想反例，不扮演宣布终局答案的权威。

素材：[wenwen-v1.png](wenwen-v1.png)，透明背景、1208×1302 像素位图。没有沿用 JOJO 小鸡的轮廓与配色。

## 阿映自媒体班

角色名：阿映。“映”联系画面、拍摄与表达。原创小浣熊，灰蓝皮毛、清楚的深色眼罩和条纹尾巴，杏橙针织帽、青绿色背带，带一本小拍摄手记和场记板。它的气质是观察、提问与动手实践。

素材：[aying-v1.png](aying-v1.png)，透明背景、1312×1199 像素位图。与问问有不同的剪影、色彩和道具，适合独立头像、站点图标和教练角色。

## 生成记录

两张图通过内置 `image_gen` 分别生成，各自为一个独立资产。没有使用 CLI，也没有以 SVG 或代码形状替代。原始生成图保持不变，项目内保存了所选副本。实际尺寸和透明通道以文件检查为准。

完整最终提示词见 [prompts.json](prompts.json)，键 `wenwen` 和 `aying` 对应上述两张图。两者都要求：原创角色、可爱的清晰像素块、完整身体与安全留白、透明背景、无文字和水印、不像黄色小鸡。后续应用时需要另行整理头像安全区和表情素材，不能把全身稿直接挤进现有表情格。
