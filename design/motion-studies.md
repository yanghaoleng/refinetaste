# 人物与动作练习：教材主题与案例设计

参考 Richard Williams 的 *The Animator’s Survival Kit*，官方书目：https://www.faber.co.uk/product/9780571238347-the-animators-survival-kit/ 。参考的是定时与间距、步行、跑跳、柔韧与重量、表演和制作顺序等概念；以下为本项目原创教学改编，不复制书中插图、原题或逐页内容。

| ID | 学习目标 | 比较与评价 |

| 60 | 小尺寸轮廓辨识 | 像素设定、64px 预览和剪影 |
| 61 | 转面体积一致 | 像素角色正面、侧转、侧面 |
| 62 | 关节连接与旋转支点 | 同一三维角色与角度、同节奏，只改变肩部支点 |
| 63 | 提起重物的发力过程 | 同一箱子、相同起终点高度；比较身体准备与平衡 |
| 64 | 弹性与压缩伸展 | 相同自由落体；不同触地形变和反弹；三轴缩放乘积为 1 |

## 呈现与边界

- 球、积木、箱子及动态角色均为真实三维顶点、三角面与三维变换，通过正交投影、深度排序、面法线光照绘制到二维 Canvas；不是图片缩放冒充模型。静态形象与转面继续使用像素位图。
- 比较共用 3200ms 学习片段和单一时钟。第 70 题实际移动区间为 1000ms，其余为观察停留。观察时间轴按 30 帧/秒、0—96 帧提供刻度。轨迹显示等时间间隔采样，不用匀距离取点掩盖间距变化。
- 减少动态效果时默认静止，可手动播放；逐帧和拖动会暂停两版。后台暂停，离题取消时钟。三维绘制按观察刻度更新，避免重复绘制同一帧。
- 支撑脚测试在世界坐标中验证相对固定地面的位置。球的接触与体积是风格化约束；人物关节、支撑与配件是定性教学模型，不是精确解剖或完整物理仿真。
- 不把缓动、长预备、大形变、更多帧或更慢直接等同于更好。答案必须结合题设，并解释反例的适用场景。
- 旧题目与章节 ID 不变；新增 70—73。已启动的十题轮次和仍打开的旧十题标签页继续按其题目清单结算，新增题不进入旧轮次的应答分母。
