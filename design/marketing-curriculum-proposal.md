# 营销推广学习路径：课程与来源

研究与实现日期：2026-10-23。承接现有 8 章，新增第三条路径「营销推广」，第九至十五章，每章 8 题（4 道比较判断、4 道开放实作），共 56 题。全站为 15 章、130 题。以下是课程设计依据，实际题目与参考思路以 `dist/course.json` 为准，原创编写源为 `scripts/build-marketing-course.py`。

目标：产品开发或内容制作完成后，能明确推广对象和目标，先服务用户、收集反馈并迭代产品，再建立品牌与账号表达，选渠道、组织转化路径、安排小规模投放验证，并判断结果。国内场景优先，出海以具体市场为单位，避免把海外视为单一市场。

案例使用虚构的效率工具、创作者内容与生活消费品，明确区分订阅产品、一次性购买和内容消费。平台用于提供真实语境，不把个别平台、某个阶段的经验当成普遍规律。与原第四章产品验证、第二章运营设计的区别：本路径练习面向市场的触达、传播、获客和经营，不重复产品内页面设计。

## 九、营销基础与市场定位

核心概念：目标人群与使用情境、细分与定位、价值主张、利益与证据、品牌与效果、推广目标、渠道假设。

| 类型 | 题目与情境 | 学会什么 |
| --- | --- | --- |
| 判断 | **产品做完了，第一步就该买流量吗？** 对比一份直接列平台预算的计划，和一份先说明目标用户、问题、价值与转化动作的计划，判断小团队首次推广哪份更有验证依据。 | 推广前提与可检验假设；不是一律禁止先投放测试。 |
| 判断 | **“适合所有人”，真的更容易卖吗？** 两份效率工具文案，一份罗列人人可用，一份面向需要快速整理会议记录的小团队，并有需求证据。 | 细分与定位，不把人群越窄永远越好。 |
| 判断 | **“支持十二种功能”和“解决一件麻烦”，谁更说得清？** 在同一受众与任务下比较功能清单和有事实支持的场景价值。 | 功能、利益和证据，不是排斥专业参数。 |
| 判断 | **看过、记住、注册、购买，是同一个目标吗？** 给出不同阶段的活动目标与指标组合，判断是否对应。 | 曝光、认知、意向与转化的区别。 |
| 实作 | **给你的产品写一张推广定位卡。** 写给谁、何时需要、原来怎么解决、为什么选择你、证据是什么、这次希望采取什么行动。 | 将定位变成可执行的简报。 |
| 实作 | **同一个产品，向两种人怎样介绍？** 面向独立创作者与团队负责人分别写一句价值表达，说明证据和侧重点怎样改变。 | 区分细分表达与随意改变品牌承诺。 |
| 实作 | **产品、内容和品牌，各自承诺了什么？** 用一条产品演示或知识内容，说明它如何带来价值、积累品牌联想，又引导下一步行动。 | 内容价值与商业价值可以相互支撑。 |
| 实作 | **第一轮推广，怎样证明方向值得继续？** 给出一个明确目标、主要假设、验证方式、成功与停止条件。 | 先定义要学到什么，再决定动作。 |

## 十、私域服务、留存与产品迭代

优先顺序：用户获得价值 → 服务与反馈 → 产品迭代 → 留存诊断 → 自愿转介绍。私域是持续连接和服务用户的方式，不以拉群或聊天消息量代替产品价值。

| 类型 | 题目 | 学会什么 |
| --- | --- | --- |
| 判断 | 第一批用户进群后，先让他们做什么？ | 帮助完成首次关键任务，先兑现价值 |
| 判断 | 群里最响亮的建议，就该最先开发吗？ | 区分要求与需求，按影响、证据和成本排序 |
| 判断 | 群很热闹，用户真的留下来了吗？ | 以同期队列的有价值行为观察留存 |
| 判断 | 问题修好了，反馈闭环就结束了吗？ | 通知、修复、邀请重试并验证结果 |
| 实作 | 设计一次真正帮助上手的首周服务 | 在人员和时间约束中安排上手支持 |
| 实作 | 把一条抱怨变成可迭代的问题 | 澄清任务、障碍、事实与假设 |
| 实作 | 哪些人没再回来，你准备怎样理解？ | 区分周期性需求、产品阻碍与一次性任务 |
| 实作 | 什么时候，再谈自愿转介绍？ | 用户已得到价值后自愿分享，不强制邀请 |

## 十一、品牌起号与内容增长

核心概念：账号定位、主页承诺、品牌识别、内容栏目、冷启动验证、内容结构、互动质量、创作者合作。

| 类型 | 题目与情境 | 学会什么 |
| --- | --- | --- |
| 判断 | **看完主页，我知道为什么要关注你吗？** 比较同一品牌的两套头像、简介、置顶与近期内容组合。 | 账号承诺、身份清晰和内容一致。 |
| 判断 | **统一品牌，是每条都贴同一个 Logo 吗？** 比较只有标志统一、表达混乱的账号，与视觉、语气、观点和内容价值相互支持的账号。 | 品牌识别不等于单一标志。 |
| 判断 | **一条跑题内容爆了，该不该整个账号跟着转？** 给出播放、关注人群和有效咨询数据，比较跟风转向与继续验证的方案。 | 热度、目标人群与品牌关联。 |
| 判断 | **开头很吸引人，为什么反而失去信任？** 两版都吸引注意，一版用正文兑现承诺，一版夸大标题且产品迟迟不出现。 | 内容钩子、价值兑现和行动引导。 |
| 实作 | **给一个新品牌安排首批八条内容。** 至少包含两个可持续栏目，标明每条面向谁、提供什么价值、想验证什么；八条是本题约束，不是起号阈值。 | 栏目与验证设计，而不是随机发内容。 |
| 实作 | **把功能介绍改成一条值得看完的内容。** 写开头、核心证明和结尾行动，并说明品牌如何自然出现。 | 内容结构及品牌与叙事的结合。 |
| 实作 | **品牌账号和创始人账号，谁来讲这件事？** 根据素材、可信度、持续供给和团队成本选择方案，可组合使用。 | 品牌账号、个人表达与运营能力匹配。 |
| 实作 | **选一位创作者合作，你会看哪些证据？** 比较受众关联、内容能力、评论质量、报价和合作形式，并写一份包含真实体验、披露与评价方式的简报。 | 创作者匹配与合作边界，不只看粉丝数。 |

## 十二、国内渠道与转化链路

核心概念：推荐与搜索、种草与承接、内容与交易、公私域协作、私信与线索、渠道适配、落地与跟进。使用小红书、抖音、微信生态与 B 站等案例，但答案由题设中的受众行为证据决定，不按平台刻板印象判分。

| 类型 | 题目与情境 | 学会什么 |
| --- | --- | --- |
| 判断 | **用户正在搜答案，你却只安排了刷屏曝光？** 已知目标用户会搜索“会议记录工具对比”，判断两份内容分发计划是否承接主动需求。 | 搜索意图与推荐发现；两者可以组合。 |
| 判断 | **收藏很多，为什么问的人很少？** 小红书风格的教程内容有收藏，但主页和产品信息无法帮助用户判断是否适合自己。 | 种草指标与产品意向之间的缺口。 |
| 判断 | **短视频很热闹，直播间却接不住人？** 广告内容、直播讲解、产品与优惠各自承诺不同，判断优先修复哪种链路。 | 前后承诺一致、内容到交易的衔接。 |
| 判断 | **让用户加了微信，就完成转化了吗？** 对比只拉群与提供明确服务、合理触达节奏和后续体验的方案。 | 私域是持续服务关系，不是收集联系人数量。 |
| 实作 | **为一个新产品选一个主渠道和一个承接渠道。** 给出目标用户行为材料，在小红书、抖音、微信生态、B 站等选项中提出计划，说明暂缓哪些渠道及原因。 | 有证据的渠道选择，避免全平台铺开。 |
| 实作 | **画出从看见到试用的完整路径。** 安排内容、主页、平台允许的组件或入口、落地页与试用步骤，找出两处可能流失的位置。 | 路径设计与规则内承接；不把任意跨平台导流视为默认可用。 |
| 实作 | **一份演示，怎样变成三个渠道的内容？** 同一事实材料分别面向搜索笔记、短视频与深度演示，调整结构、信息密度和行动引导。 | 跨平台改编，不机械搬运。 |
| 实作 | **咨询来了，为什么还是没成交？** 阅读虚构的内容、咨询与跟进记录，区分线索不匹配、承诺不清和响应不及时，提出验证办法。 | 内容、获客与服务衔接。 |

## 十三、付费投放入门

核心概念：营销目标与优化目标、计费与优化的区别、CPM/CPC/CTR/CVR/CPA、加热与广告、转化信号、素材测试、预算与边际效果。以国内产品为主要案例，同时说明概念的可迁移性。

| 类型 | 题目与情境 | 学会什么 |
| --- | --- | --- |
| 判断 | **想要有效咨询，为什么只优化点击？** 两份推广设置分别优化便宜点击和事先定义、可记录的有效咨询；给出目标与追踪条件。 | 优化目标应与业务目标、数据条件相匹配。 |
| 判断 | **点击更便宜，获客一定更便宜吗？** 同期同口径：A 花费 100 元、100 次点击、1 名新付费客户；B 花费 80 元、40 次点击、4 名新付费客户。产品、退款与新客价值相同。 | A 的 CPC 为 1 元、广告花费/新客为 100 元；B 为 2 元和 20 元。广告花费/新客不冒充完整 CAC。 |
| 判断 | **给内容加热，就等于已经建立购买优化了吗？** 给出两份明确的目标与追踪配置，而非仅凭工具名称判断。 | 区分内容曝光、互动放大与可追踪的业务转化优化。 |
| 判断 | **刚有两单，就应该立刻加大预算吗？** 给出观察时长、订单延迟、退款、样本量和成本波动信息，判断放量证据是否充分。 | 学习与不确定性；不教授固定的“几单必放量”规则。 |
| 实作 | **写一份最小投放简报。** 包括目标市场、受众、价值、素材、转化事件、预算上限、观察窗口与停止条件。 | 把花钱动作组织为可控验证。 |
| 实作 | **只有两份素材，怎样测试才知道差别？** 保持目标、受众与落地一致，优先比较一个主要创意假设，说明需要看哪些结果。 | 单变量验证与测试口径。 |
| 实作 | **广告有人点，落地页没人继续。** 从承诺、加载、设备、价格、信任和步骤中提出排查顺序，说明如何用证据区分。 | 不把所有问题都归因于素材或定向。 |
| 实作 | **预算有限，下一轮该继续、换素材还是停下？** 提供分时段、分素材的成本、质量与成交数据，要求提出有条件的下一步。 | 边际效果、质量与预算管理，不做收益保证。 |

## 十四、出海营销与本地化

核心概念：具体市场选择、本地用户研究、语言与文化适配、搜索与信息流、创作者与社区、独立站/应用/平台承接、付费与自然增长、信任与合作披露。

| 类型 | 题目与情境 | 学会什么 |
| --- | --- | --- |
| 判断 | **把中文翻成英文，就算完成本地化了吗？** 对比直译与根据题设目标市场调整案例、表达、价格呈现和下一步行动的页面。 | 语言只是本地化的一部分。 |
| 判断 | **用户正在搜索，还是需要先理解这个新品类？** 同一市场中比较 Google 搜索广告与 Meta/TikTok 等信息流发现方案，按需求证据、素材和目标选择。 | 主动意图与需求发现；平台不被限定为单一用途。 |
| 判断 | **点击来自目标国家，为什么订单仍然很少？** 分别给出币种、支付方式、配送、时区、客服与注册步骤等材料。 | 流量以外的承接与信任。 |
| 判断 | **送了免费产品，也能当作完全独立的推荐吗？** 明确题设面向美国消费者，比较清楚披露合作关系与隐去关系的内容。 | 美国 FTC 语境下的实质关系披露，不能扩展为所有国家统一规则。 |
| 实作 | **只选一个市场，怎样做第一轮验证？** 从需求、语言、竞争、渠道、交付与支持能力提出一个市场假设，而不是泛称“欧美”。 | 市场选择与小规模验证。 |
| 实作 | **把国内表现好的内容改成当地用户看得懂的版本。** 调整情境、术语、人物与证明材料，保留真实产品价值，并安排本地受众反馈。 | 本地化创意；不假造当地用户与评价。 |
| 实作 | **除了买广告，还有什么获客方式？** 在有用的搜索内容、创作者合作、社区参与、产品演示和自愿订阅中选合适组合，说明时间成本和验证方式。 | SEO 与内容、社区等不同渠道的积累机制，不保证自然流量。 |
| 实作 | **同一产品，两个市场结果相反，你会先查什么？** 给出不同市场的内容、渠道、语言、承接与用户反馈，设计排查顺序。 | 不以国家标签替代具体证据。 |

## 十五、效果衡量与增长实验

核心概念：漏斗与分母、广告转化成本与 CAC、ROAS 与利润、归因与去重、实验与增量、留存与复购、品牌效果与短期成交。

| 类型 | 题目与情境 | 学会什么 |
| --- | --- | --- |
| 判断 | **播放量翻倍，这次推广就更成功了吗？** 目标为合格试用，比较曝光、访问、合格试用、付费与退款数据。 | 指标服务于目标，而非只挑好看的数。 |
| 判断 | **ROAS 是 2，就一定赚了吗？** 假设净收入 10000 元、广告费 5000 元、扣广告前毛利率 30%，忽略其余费用。 | 毛利 3000 元不足覆盖广告费，扣广告后为 -2000 元；ROAS 不等于利润或 ROI。 |
| 判断 | **两个平台都说带来了订单，可以直接相加吗？** 两平台各报告 60、50 单，后台去重后为 80 单；观察窗口与订单定义已给定。 | 平台归因可能重叠，区分归因信用与唯一订单。 |
| 判断 | **改了封面后转化率涨了，能认定是封面的作用吗？** 同期还改了价格、受众与促销，对比只有前后对照和合理随机分组的证据。 | 相关与因果、混杂与对照。 |
| 实作 | **给一轮推广画出指标漏斗。** 从曝光、点击、注册、合格试用到付费，标明每个比率的分子、分母、时间窗与去重方式。 | 漏斗诊断与一致口径。 |
| 实作 | **广告费不是唯一成本，怎样算获客？** 给出广告、内容、销售等成本与新老客户数据，区分广告 CPA、CPL 与明确口径的 CAC。 | 成本口径；转化事件与付费新客不是同义词。 |
| 实作 | **当月还没回本，怎样判断值得继续？** 明确订阅型产品场景，检查分批新客的留存、贡献利润、回收周期和预测不确定性；一次性商品另给复购条件。 | 不把收入预测当利润，也不把未来 LTV 当已收到的现金。 |
| 实作 | **这次增长，有多少是推广真正新增的？** 设计一个适合体量的对照或分批验证方案，写出主要指标、观察窗口、保护指标与下一步。品牌目标可采用合适的认知研究，不能把品牌搜索上涨直接当成因果证明。 | 增量、复盘与长期品牌效果。 |

## 题型与素材

- 判断题提供相同任务下的两份内容、账号主页、渠道计划、落地路径或数据卡，让学员选择并解释；避免仅靠文案长度、配色精细度或样本规模泄露答案。
- 实作题评价目标是否清楚、依据是否具体、方案是否能执行、验证口径是否一致；开放题允许不同有依据的渠道与品牌策略。
- 建议贯穿一个虚构的效率工具品牌，再穿插内容产品与实物商品，避免把所有产品都按电商下单评价。
- 静态情境图沿用位图；主要比较文字、计划和数值的题目使用真实页面元素与数据卡。仅在解释流动、漏斗或分配过程确有帮助时使用简洁三维动画，不为每道题强行动效。
- “起号”解释为验证账号承诺、稳定供给和目标受众反馈。不把养号天数、必发条数、固定发布时间或保证起量的技巧当成标准答案。
- 国内各渠道的跨平台导流、商业合作、认证和投放能力以当期官方规则及账户资格为准；课程不考易失效的按钮位置、统一预算门槛或所谓算法权重。
- 提到披露或授权时明确市场与情境；不把美国 FTC 规则泛化到全部海外市场，也不把站外跟踪或再营销视为默认已获授权。
