# 从产品设计到 AIGC 内容创作

目标是建立独立完成作品的判断与流程，不把答题正确率等同于真实项目能力。真实制作还需要工具练习、用户反馈与作品迭代。

| 路径 | 章节 | 产出能力 |
| --- | --- | --- |
| 线上产品设计 | 一、基础设计原则 | 给信息安排主次、分组与阅读顺序 |
| 线上产品设计 | 二、运营设计 | 做清楚、可信、符合产品语境的运营入口 |
| 线上产品设计 | 三、体验设计与使用场景 | 连接任务、路径、状态、错误与恢复 |
| 线上产品设计 | 四、产品设计与验证 | 在业务与可用性约束下提方案、定验收、做验证 |
| AIGC 内容创作 | 五、单张画面与 AIGC 创作 | 从绘本读图进入构图、情绪、提示要求与生成图质检 |
| AIGC 内容创作 | 六、分镜与镜头设计 | 拆镜头任务、保持方向与动作、预演时长、管理参考 |
| AIGC 内容创作 | 七、长视频结构与叙事 | 建立主线、组织段落、回查素材、分镜头制作与粗剪 |

每章 8 题，共 56 题；32 道比较判断、24 道 AI 对话实作。每题保留不同问法，选择题可以反向查找需修改的方案，方案位置随机。实作题先由用户表达，再由模型根据该题核心原则判断，允许不同有效解法。

第五章原有 16 张原创绘本插图继续复用；以绘本为入口训练通用的图像表达，不把绘本原则机械套成所有作品的固定审美标准。第六章使用原创 SVG 分镜，第七章使用原创故事、分镜和有时间索引的模拟纪录素材。题中灯塔、女孩、修灯纪录均为教学创作，不是真实采访或历史记录。

## 编写边界

- 分镜先解决观众要知道什么，再考虑镜头与生成参数。
- 180 度规则是保持空间可读的常用方法，允许有意越轴，但要交代方位。
- 秒数与故事结构是可验证的方案，不是唯一比例公式。
- 素材归纳区分事实、说法与推测，不为了顺畅而补造因果。
- AIGC 先锁结构与参考，再逐镜生成、组合与核对；参考一致不等于工具能保证一致。
- 本轮增加判断与流程练习，未接入图像或视频生成工具；模型继续用于对话与简答判定。

## 参考范围

依据以下公开教育资料的通用概念编写原创题目，没有复制原片、课程画面或原题：

- [Pixar in a Box：The art of storytelling](https://www.khanacademy.org/partner-content/pixar/before-the-story/storytelling)：视觉语言与故事结构的课程范围。
- [Adobe：180-degree rule](https://www.adobe.com/creativecloud/video/discover/what-is-the-180-degree-rule.html)：人物关系轴线、空间连续性与有意改变方位。
- [Google DeepMind：Veo prompt guide](https://deepmind.google/models/veo/prompt-guide/)：视频提示中对主体、动作、环境和镜头运动的具体描述；不依赖某个模型版本的时长或生成能力。
- 既有来源：[绘本练习](picturebook-sources.md)、[运营规范练习](operations-sources.md)。
