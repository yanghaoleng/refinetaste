# 小鸡表情图集

以现有 chick-eyes-512.webp 为角色参考，由 imagegen 生成并编辑。6 列 × 3 行，每两个相邻格是一组两帧动画。

顺序：neutral、happy、thinking / curious、surprised、encouraging / empathetic、confused、playful。

提示：保持黄色小鸡与金色圆眼镜，夸张漫画表情；每格为大脸特写，黄色脸部铺满方格，最终以圆形裁切，不露头部轮廓、身体或披风。底部仅露圆润红领巾结和蝴蝶结上缘的一部分。所有格子等宽等高，眼镜与五官保持一致缩放和位置，不加文字与网格。

安全区检查：18 格大脸铺满，五官位于圆形区域内，底部露部分红色结饰，不出现身体或头部轮廓；图集宽高比为 2:1。
