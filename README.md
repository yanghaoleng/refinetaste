# 目光 · 审美练习室

面向运营和设计协作的中文学习型测验。直接运行 `python3 -m http.server 5173 --directory dist`，在浏览器打开 http://localhost:5173。

包含八个练习：名片四原则、资源位调性、优惠信息层级、用户路径和协作反馈。答题后展示对应解析，支持预设追问、自主反思、当前浏览器笔记和文本导出。响应式布局、明暗主题与减少动态效果支持。

当前所有业务场景均为教学模拟，未使用真实业务素材。讲解来自课程预设，尚未接入语言模型。后续接入模型须增加服务端接口，将密钥保留在服务端，传入题目、选项和用户问题。不要在静态页面放置 API 密钥。

基础概念来自用户指定的《写给大家看的设计书》四原则；本项目的名片、例题和讲解均为原创教学示例，并非书中原文或插图。
