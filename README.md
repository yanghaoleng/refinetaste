# 设计积累 · RefineTaste

把「感觉不对」变成说得清的设计判断。面向运营与设计协作的中文审美练习网站。

- 网站：https://mikeywa.site/refinetaste/
- 统计后台：https://mikeywa.site/refinetaste/data/

## 学习内容

40 个练习分为五章，每章 8 题，可独立开始。首页保持单一入口，进入后选择课程。

- **低阶：基础设计原则**。名片、海报、菜单、电子票、表单、状态提示，建立对比、分组、对齐与信息层级的意识。
- **中阶：考虑使用场景**。APP 资源位、优惠条件、点击承接、错误恢复、空状态、注意力分配与品牌活动。
- **高阶：设计取舍与判断**。数据表达、实验判断、地图信息抽象、破坏性操作、增长与信任、跨角色评审、包容性与综合路径审核。

共 24 道比较题、16 道开放题。开放题以对话作答，支持本机草稿与进度、豆包 Mini 多轮讨论、将同题对话保存到笔记。每章结算统计比较题与简答题判断，简答题按核心原则进行 AI 辅助判定，不评价审美能力。每次进入一章会重新编排题序、问法与 A/B 位置，原有草稿与笔记保留。

基础概念参考《写给大家看的设计书》四原则，案例与讲解均非书中原文或插图。线上参考包括 [GOV.UK 按钮](https://design-system.service.gov.uk/components/button/)、[错误摘要](https://design-system.service.gov.uk/components/error-summary/)、[W3C 颜色信息原则](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)、[London Transport Museum 的 Beck 1933 地铁图资料](https://shop.ltmuseum.co.uk/products/harry-beck-underground-map-1933)。每道相关题附来源，画面均为原创教学示意，不是官方截图。题库及评价维度在 `dist/course.json`，前后端共用版本 2。

模型点评由服务端代理调用豆包（兼容 HTTPS Chat Completions），结合题目和作答，从观察依据、用户视角、取舍意识、验证方法给出反馈与一个追问。服务不持久存储作答或点评正文，只在当前请求中发送给模型；浏览器保留草稿与主动保存的笔记。提供商的数据处理规则仍适用，模型故障时显示真实错误，可重试或自行复盘，不伪造点评。

## 运行

仅看前端：`python3 -m http.server 5173 --directory dist`。

完整站点使用 Python 3.10+，无需安装第三方依赖。设置环境变量后运行 `python3 server/app.py`，访问 `http://localhost:8797/refinetaste/`。生产访问码只配置在服务器环境中，不包含在公开源码。

| 变量 | 含义 |
| --- | --- |
| `REFINETASTE_SECRET` | 至少 32 字符的随机 HMAC 密钥 |
| `REFINETASTE_PIN_SHA256` | 自选六位数字访问码的 SHA-256 |
| `REFINETASTE_DB` | SQLite 文件绝对路径，默认 `.runtime/analytics.sqlite3` |
| `REFINETASTE_ORIGINS` | 逗号分隔的允许来源，本地开发加入 `http://localhost:8797` |
| `REFINETASTE_AI_KEY` | 仅服务端保存的模型 API Key |
| `REFINETASTE_AI_BASE` | HTTPS API 基址，默认火山方舟 `/api/v3` |
| `REFINETASTE_AI_MODEL` | 模型或推理接入点 ID |
| `REFINETASTE_AI_LABEL` | 点评来源显示名 |
| `PORT` | 仅监听 127.0.0.1，默认 8797 |

环境文件不入库。参考 `.env.example`。服务不会自动加载本地 `.env`；通过 shell 或 systemd 注入。

## 数据口径

匿名事件从接入后开始累计，不回填旧站记录。访客随机 ID 经服务端 HMAC 后保存，匿名访客数不等于真实人数。换设备、清空存储会重复计数；脚本拦截或网络错误会漏计。

- 访问：页面打开次数。
- 练习启动：每次进入或重新练习，创建新轮次。
- 首次答题：每轮每题只计第一次提交；开放题仅计提交，不参与正确率。主动作答后申请点评即计提交，模型失败不影响表达记录。
- 完成：新版提交本阶全部 8 题并到达回顾；旧版入口 1 / 5 / 7 分别需要 8 / 4 / 2 题。旧版事件默认版本 1，数据库自动迁移并保留历史。
- 期间完成率：所选期间启动的轮次中，已完成轮次 / 启动轮次，按启动日归属。跨期开始的旧轮次不纳入本期练习分析。
- 保存笔记：只计操作，不上传正文。

时区 `Asia/Shanghai`，支持 7 / 30 / 90 个自然日（含今日）。事件滚动保留 90 天，仅在收到事件时执行过期清理。历史覆盖不足时不构造环比。后台返回汇总，不提供原始事件、个人轨迹、IP 或 UA。

`?qa=1` 开启当前标签页的 QA 模式，排除统计；`?qa=0` 恢复采集。

## 接口与权限

- `GET /refinetaste/api/health`：服务与存储检查。
- `POST /refinetaste/api/collect`：来源校验、体积限制、节流、事件白名单与去重。
- `POST /refinetaste/api/review`：30—2000 字开放题；来源校验、格式限制、每 IP 哈希每分钟 4 次、每日 32 次、全站每日 300 次、并发 4 个。日额度由 SQLite 持久限制；失败请求退还日额度。无密钥时明确返回不可用，密钥不进入静态文件。
- `POST /refinetaste/api/login`：服务端验证访问码，5 次失败后限流 5 分钟。
- `GET /refinetaste/api/summary?days=7`：需要有效服务端会话。
- `POST /refinetaste/api/logout`：失效当前会话。

管理 cookie 使用 HttpOnly / Secure / SameSite=Strict，无持久化过期属性，服务端最长 8 小时有效，重启服务使会话失效。登录与采集的临时限流键使用 IP 的 HMAC，仅留内存；应用不记录请求日志，Nginx 本路径访问日志关闭。六位码适用于小规模汇总看板，未实现多用户账号。匿名事件可由浏览器伪造，不应用于审计或人员考核。

## 部署

`ops/refinetaste.service` 使用 systemd DynamicUser 与独立 StateDirectory。发布到 `/opt/refinetaste/releases/<release>`，`current` 软链接原子切换；数据库在 `/var/lib/refinetaste/`，环境配置在 `/etc/refinetaste.env`，均在发布目录之外。Nginx 在既有站点引入 `ops/nginx-refinetaste.conf`，只路由 `/refinetaste`，不修改其他应用路径。核验 `nginx -T` 的实际启用入口；本次主站的 `/etc/nginx/sites-enabled/mikeywa.site` 为独立文件，并非指向 sites-available 的软链接，不能只编辑后者。

更新时先测试、提交、推送，再上传版本，验证服务、Nginx 配置、授权/未授权接口与前端资源。回滚切换 `current` 至上一个目录并重启服务。本版 schema 向后兼容，勿删除数据目录。备份可使用 SQLite backup API，在服务器单独管理，不上传公开仓库。

## 品牌与图标

品牌图标采用小鸡的星星眼表情，网站、统计页、favicon 与 Apple Touch 图标保持一致。导航图标为 96/192px WebP，favicon 为专用 16—64px ICO/32px PNG，主屏幕图标为 180px PNG。原图与派生资源位于 `dist/assets/`，来源见 `design/brand-icon-prompt.md`。

界面图标统一使用 [Iconoir](https://iconoir.com/) 7.12.1 官方 regular SVG，统一 2.5px 线宽；源码子集和 MIT 授权位于 `vendor/iconoir/`，通过 `python3 scripts/build-icons.py` 生成自托管 `dist/icons.svg`。不依赖外部 CDN。图表路径属于数据可视化，并非界面图标。

色彩以叫叫官网 CSS 中的黄色 `#ffdc00` 和深棕 `#260f00` 为参考，跟随系统亮暗主题：浅色背景使用深棕按钮和纯白粗体字，暗色背景为纯黑；不提供手动主题开关。课程、案例、按钮与统计图表使用同一套色彩变量。

## 动效

基于 taste skill 的 8 / 8 / 3（设计变化 / 动效强度 / 信息密度），使用原生 Web Animations 与 IntersectionObserver。页面与卡片分批入场、题目先退后进、弹窗含退场、展开说明淡入淡出，按钮/导航/输入框/数字键盘提供即时反馈。界面入场使用透明度与变换；头像采用两帧精灵图循环，无 scroll 监听。尊重系统减少动态效果，切换时会立即结束正在播放的动画。主题由 `theme.js` 在首屏绘制前读取系统偏好，`theme.css` 定义最终配色，`motion.js` / `motion.css` 定义共享动效。

## 本地交互更新

练习按聊天时间线组织：题干、情境和开放提问是 JOJO 的第一条消息，随后逐条发送完整的 A、B 方案或案例，再进入讨论。顶部为紧凑单行：返回箭头、短进度条、居中的 JOJO 头像和右侧笔记入口，不显示昵称。头像两帧循环，并每隔7—8秒在当前语气对应的表情中变化；页面隐藏、离开练习或启用减少动态效果时停止自动变化。每题收藏位于底部「下一题」旁，二者同时出现。比较题以选项上的勾叉显示判断，随后自动展开聊天。所有开放题也以对话作答。课程目录与题目使用无文字进度条，目录进度条悬停展示知识点。下一题支持 N 快捷键，输入时不触发。「下一题」旁的书签收藏当前题目，同题的草稿、点评和对话同步保存在当前浏览器；「我的笔记」先展示列表索引，再进入详情；从按钮下方以非阻拦浮层打开，宽屏（1280px 起）采用右侧栏并为练习让出空间，支持返回列表，兼容旧版笔记，不提供导出功能。取消收藏不删除题目进度或对话。对话复用点评接口的来源限制、并发和日额度；每次最多发送最近 12 条消息、合计 18000 字，不在服务端保存正文。未配置模型时显示真实不可用提示。

### 文字与数字动效

使用 Calligraph 1.4.1：题干和消息采用 `text`，收藏数量采用 `slots`。React/Motion 仅用于文字组件，前端已打包、自托管，不依赖 CDN。修改 `src/text-motion.jsx` 后运行 `npm ci` 和 `npm run build:text`；普通启动无需安装 Node 依赖。Text 的逐字首次入场做了有上限的分批时间适配，支持中文换行、减少动态效果和离开题目时清理组件。第三方授权位于 `vendor/text-motion/THIRD_PARTY_LICENSES.txt`。

### 教练表情

`dist/assets/chick-emotions.png` 是九组两帧表情图集，每行六格、三行；`chick-positive-emotions.png` 补充六组正向表情，每行六格、两行。保留金色圆眼镜，圆形头像用大脸铺满，底部仅露圆润红领巾结的一部分，不露头部外轮廓或身体。头像固定在导航正中，消息中不重复显示；模型返回白名单 emotion 字段更新顶部表情，未知值回退 neutral。所有十五种表情按两帧循环，周期 1.2 秒；减少动态效果时静止。生成说明见 `design/chick-emotions-prompt.md`。

### 头像资源优化

运行时只加载两张 WebP 图集（576×288 和 576×192），单帧 96px，合计约69KiB，覆盖当前44/48px头像的两倍像素密度。HTML preload 提前请求，进入课程目录前完成解码并保留图片引用，切换表情无需再次下载原始 PNG。生成源 PNG 保留作开发素材；重建压缩图和星星眼图标使用 `scripts/build-coach-assets.py`（开发环境需 Pillow，服务器运行不需要）。

### 粒子目录与回复状态

五章目录使用 Canvas 单色点阵几何（层叠平面、交叠圆环、扭转曲面、弧形书页），平时极慢流动，整行悬停时加速并出现点阵波纹。整行是原生按钮，可鼠标或键盘进入；进度条上的知识点浮层独立操作。图形对齐统一点阵，DPR最高2、最高30fps，按透明度批量绘制；离开目录、标签隐藏、图形离屏时暂停，减少动态效果时只绘制静态形体。几何生成在本地，不涉及上传。

模型请求期间在左侧显示三点跳动气泡，正式回复、失败、重试和离开题目时清理；不把加载气泡存入笔记或对话历史。

### 第五章：读懂画面与故事

8 道原创绘本鉴赏练习（4 道比较判断、4 道对话观察），讨论视觉焦点、视线、气氛、图文互补、连续叙事、翻页、视角和细节。参考范围与图片说明见 [绘本练习来源](design/picturebook-sources.md)。

### 第二章：运营资源基本原则

8 道比较判断，依据用户提供的《App 运营资源审核规范》，案例全部用页面元素和 SVG 重绘。来源与范围见 [运营练习来源](design/operations-sources.md)。章节展示顺序调整不会修改原题 ID。

### 章节结果与笔记复习

每次完整章节记录本轮全部题目正确率，简答题在作答前不显示原则，由 AI 判定是否符合核心原则；完成整章且全部题目正确才显示绿色通过，否则显示重新测试。结果按稳定的章节首题 ID 存在当前浏览器中，重新完成一轮会更新该章结果。笔记详情包含题干、案例、所选结果与聊天框；续聊与练习共享同一题的对话历史，保留输入草稿及失败重试。

网站品牌图与 favicon 每次页面打开或刷新时，从 15 种表情随机选择同一张，避免与上一次连续重复；图标派生为 96px WebP、32px PNG 和 180px 触屏图标。

### 当前答题与动效

每题有基础与另一种问法；比较题的另一种问法改变表达目标或检查方向，答案随提问改变，再独立打乱 A/B。每轮八题顺序打乱，固定题 ID 保持笔记和统计稳定。模型服务验证变体 ID、选项置换后再构造上下文，不直接采用客户端提供的题目正文。每种问法与选项顺序的历史分开保留；收藏记录保存当时的完整题目快照。比较题埋点的 choice 规范化回原题的对错含义，以保持历史正确率口径；它不代表界面展示的 A/B 位置。

新消息先呈现第一段，文字入场完成后保留约 1.6 秒阅读间隔，再出现第二段并移动头像；输入框随后出现。标题、背景、提问逐段入场。已有对话不重播。结算先呈现不带百分号的分数，等分数动画与短暂停留结束后出现说明，只留重打按钮。计数和分数使用本地 Manrope 700 数字子集（OFL 许可），Slot 轮盘严格裁成一行。

教练消息中有限度地强调原则，概念虚线下划线可点按打开就近小窗，以通俗语言解释。富文本只支持安全的粗体和预置概念，不执行模型返回的 HTML。Sonner CSS 独立输出为本站静态资源，维持原 CSP。手机视口固定初始比例与最大比例，关闭双指和双击缩放，普通滚动保留。
